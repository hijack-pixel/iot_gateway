# Linux 物联网设备接入网关

面向物联网设备长连接接入场景的 Linux TCP 网关：自定义二进制协议解析、
epoll 高并发（ET）、慢消费者背压、线程池业务分离、心跳超时踢线，
配套多线程设备模拟器与 Qt 实时监控面板，全部指标经压测验证。

## 架构

    N 台模拟设备 ──TCP 长连接──▶ ┌────────────────────────────┐
                                 │  主线程（epoll ET + 非阻塞IO） │
                                 │   ├ 协议状态机解包（粘包/半包）  │
                                 │   ├ 设备注册表 + 心跳超时踢线    │
                                 │   └ 发送缓冲 + EPOLLOUT 背压    │
                                 └──────────┬ 任务队列 ──────────┘
                                            ▼
                                 worker 线程池（业务计算）
                                            │ 结果队列 + eventfd 唤醒
                                            ▼
                                 主线程回 ACK ── Qt 监控面板（:9001）

**协议帧格式**：`[0xA5][len 2B 大端][type 1B][payload]`
类型：0x01 注册 / 0x02 心跳 / 0x03 上报 / 0x81 ACK / 0x90 统计

## 压测数据（VMware 2C6G，本机回环）

| 指标 | 结果 |
|---|---|
| 峰值并发 | 1000 长连接稳定在线 |
| 网关开销 | 单线程 CPU ≈3%，内存 MB 级 |
| 30 分钟长跑 | 500 连接 / 90 万条消息 / 速率恒定 / 内存恒定 4MB 零泄漏 / 零残留连接 |
| ET 唤醒效率 | 30 万帧仅 22 次 epoll_wait 唤醒（约 1.36 万帧/次） |
| 慢消费者背压 | 22 万帧触发 1MB 发送队列上限踢线，正常设备零影响 |
| 线程池扩展 | 1→4 worker 吞吐 ×1.75（2 核环境上限） |

## 构建与运行

    cmake -B build && cmake --build build

    ./build/gateway --quiet [worker数]   # 网关（设备:9000 / 监控:9001）
    ./build/panel &                      # Qt 监控面板
    ./build/simulator 500 60             # 压测模拟器：设备数 运行秒数
    ./build/device dev-001               # 单设备
    ./build/device dev-002 burst         # 粘包测试（3 帧一次 write）
    ./build/device dev-999 spam 300000   # 慢消费者攻击测试
